## 🌟 Características

- **Búsqueda Dinámica:** Busca Pokémon por su nombre o número de Pokédex.
- **Explora por Habilidades:** Descubre qué Pokémon poseen una habilidad específica.
- **Datos Completos:** Visualiza detalles como tipos, estadísticas base, altura y peso.
- **Cadena Evolutiva:** Observa la línea de evolución de cada Pokémon.
- **Interfaz Limpia:** Una UI moderna y responsiva diseñada con Radix UI y Tailwind CSS.
- **Manejo de Estados:** Indicadores de carga y mensajes de error para una experiencia de usuario fluida.

## 🛠️ Stack Tecnológico

- **Framework Principal:** [React](https://react.dev/)
- **Entorno de Desarrollo:** [Vite](https://vitejs.dev/)
- **Estilos CSS:** [Tailwind CSS](https://tailwindcss.com/)
- **Componentes UI:** [Radix UI Themes](https://www.radix-ui.com/themes)
- **Fuente de Datos:** [PokeAPI](https://pokeapi.co/)
- **Cliente HTTP:** [Axios](https://axios-http.com/)
- **Gestor de Paquetes:** [Yarn](https://yarnpkg.com/)

## 🚀 Cómo Empezar

Sigue estos pasos para tener una copia del proyecto corriendo en tu máquina local.

### Prerrequisitos

Asegúrate de tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior) y [Yarn](https://yarnpkg.com/).

### Instalación

1.  **Clona el repositorio:**
    ```sh
    git clone https://github.com/tu-usuario/poke-api-app.git
    cd poke-api-app
    ```

2.  **Instala las dependencias:**
    ```sh
    yarn install
    ```

3.  **Inicia el servidor de desarrollo:**
    ```sh
    yarn dev
    ```

¡Abre [http://localhost:5173](http://localhost:5173) en tu navegador para ver la aplicación en acción!

## 📜 Scripts Disponibles

En el directorio del proyecto, puedes ejecutar:

-   `yarn dev`: Inicia la aplicación en modo de desarrollo.
-   `yarn build`: Compila la aplicación para producción en la carpeta `dist`.
-   `yarn lint`: Ejecuta el linter de ESLint para encontrar y corregir problemas en el código.
-   `yarn preview`: Sirve la compilación de producción localmente para previsualizarla.
